### 3. Paper 2 実験実施

#### paper2_01：汎用 vs 特化アンカーの比較
ファイル：`notebooks/paper2_01_domain_anchor.ipynb`
図：`notebooks/paper2_01_results.png`

**主要発見：**
```
クラスタ安定性（低いほど良い）：
  汎用アンカー : 0.047〜0.067  ← 安定性◎
  特化概念     : 0.110〜0.235  ← 安定性△

ドメイン間分離スコア（高いほど良い）：
  汎用アンカー : 0.166
  特化概念     : 0.739（4.4倍）← 識別力◎

→ 安定性 vs 識別力のトレードオフを発見（H-604 CONFIRMED）
→ 「特化概念」はアンカーではなく意味基底（Semantic Basis）と再分類
```

#### paper2_02：単語 vs 安定意味領域 vs 身体性ベース
ファイル：`notebooks/paper2_02_semantic_region_anchor.ipynb`
図：`notebooks/paper2_02_results.png`

**主要発見：**
```
総合スコア（A軸 × (1-ratio) × D軸）：
  単語ベース    : 0.098  ← 論外
  身体性ベース  : 0.535
  安定意味領域  : 0.671  ← 最も優れている（単語の6.9倍）

A軸（モデル間安定性）：
  単語ベース    : 0.101
  身体性ベース  : 0.559
  安定意味領域  : 0.704  ← 最も安定

クラスタ安定性（ratio）：
  全種類とも同等（0.036〜0.048）
  ← クラスタ安定性はアンカー種類に依存しない

D軸（摂動耐性）：全種類 1.000
```

**理論的含意：**
- 齋藤さんの最初の着想（「単語ではなく意味領域」）が実験で支持された
- 身体性ベースはregionより劣るが単語より大幅に優れる
- この結果はPaper 2の中心的エビデンスになる
