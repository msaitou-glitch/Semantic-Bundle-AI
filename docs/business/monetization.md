## 収益モデル

### Model 1：API提供（メイン）

| エンドポイント | 課金単位 |
|--------------|---------|
| bundle生成API | リクエスト数 / bundle数 |
| 意味安定化API | リクエスト数 |
| ドリフト検知API | 実行回数 |
| 整合性チェックAPI | リクエスト数 |
| 長期記憶API | 保存bundle数 / 月 |

**ターゲット：** AI SaaS企業・Agent開発企業・RAG実装企業

### Model 2：SaaS（企業向け）

企業ナレッジOS as a Service

| プラン | 対象 |
|-------|------|
| Starter | SMB・スタートアップ |
| Business | 中堅企業 |
| Enterprise | 大企業・カスタム契約 |

主な機能：
- 社内文書のbundle化・管理
- Agent memory管理
- RAG高度化
- 意味ドリフトレポート

### Model 3：ライセンス

理論・方式・非公開仕様のライセンス提供

形態：
- 非独占ライセンス（標準）
- 用途限定ライセンス
- 地域限定ライセンス
- 時限独占（期間契約）
- 共同PoC契約

## 市場背景

AIが単発応答から長期運用へ移行するほど、意味安定管理の需要が増加する。

需要を生む市場トレンド：
- Agent市場の拡大
- 企業AI導入の本格化
- 長期記憶AIの実用化
- AI人格・パーソナルAIの登場
- RAG実装の限界顕在化

**時間とともに価値が増す構造：** AIが長期化するほど意味ドリフト問題が深刻になる。
