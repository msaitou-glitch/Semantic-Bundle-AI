## 1. 中心命題

### 1.1 一文定義

> **意味束AIとは、相対的に揺らぐ意味表現を、比較的安定した認知基準（アンカー）との関係として再構成し、長期的に管理可能な意味構造へ変換しようとする試みである。**

### 1.2 重要な立場の明確化

意味束AIは「意味そのものを固定する理論」ではない。
「意味を安定参照できる構造を導入する理論」である。

```
❌ 誤った理解：アンカーは絶対不変の真理（絶対意味論）
✅ 正しい理解：相対空間の中から相対的安定構造を抽出する（準固定座標系）
```

**立場の核心：**

```
意味空間は相対的で揺らぐ
        ↓
その中にも比較的安定な部分構造がある
        ↓
それを参照基準として利用できるか？
```

これが意味束AIの本質的な問いである。「哲学的絶対座標」に寄ると恣意性・普遍主義・文化依存の問題が生じる。意味束AIはLLM空間内部の構造的安定性を利用する。

### 1.3 アンカーの本質：単語ではなく意味領域

アンカーは「単語そのもの」ではない。**安定意味領域（stable semantic region）**である。

```
❌ anchor = 単語（keyword / token）
✅ anchor = 安定意味領域

例：「danger」という単語ではなく、「危険性意味領域」
  = danger, risk, unsafe, hazardous, 危険, リスク, threat...
  の近傍意味群・多言語対応・usage clusterを含む
```

これにより意味束AIはkeyword研究・ontology研究と明確に差別化される。

### 1.4 意味安定性の主目的と副次効果

| 目的 | 内容 | PoCでの対応 |
|------|------|------------|
| **主目的** | 意味的安定性：時間・文脈・更新をまたいだ意味関係の維持 | PoC②③④ |
| **副次効果** | モデル間安定性：異なるembeddingモデル間での座標一致 | PoC①H-102 |

H-102（モデル間ランキング一致率）がFAILだったのは、主目的ではなく副次効果の検証だったため。

## 2. 着想の起点

LLMの意味表現は相対空間上で形成されるため、時間・更新・文脈変化によって意味関係が揺らぎやすい。

この問題に対して意味束AIは以下の着想から出発した：

> 「人間の認知や意味理解の中で、比較的安定している概念群を参照基準（アンカー）として採用し、そのアンカーとの関係によって意味を再表現することで、意味空間に安定座標系を導入できるのではないか」

特に、人間の身体性や基礎認知に強く結びついた概念（空間認知・時間認知・数量認知・危険性・身体感覚）は、文化差や時代変化があっても比較的安定した意味関係を維持しやすい。

## 3. Semantic Stability の4軸評価フレームワーク

**Paper 2の中心的貢献：** semantic stabilityを評価可能な問題へ変換する。

```
stability_score(anchor_i) =
  w1 * inter_model_consistency    // A. モデル間安定性
  w2 * temporal_consistency       // B. 時系列安定性
  w3 * cross_cultural_consistency // C. 文化横断性
  w4 * perturbation_resistance    // D. 文脈摂動耐性
```

### 各軸の定義

| 軸 | 問い | Paper 2での扱い |
|----|------|----------------|
| A. モデル間安定性 | 異なるembeddingモデルで近傍関係が維持されるか | 部分検証 |
| B. 時系列安定性 | fine-tuning・再学習後も位置関係が大崩壊しないか | 部分検証（PoC②） |
| C. 文化横断性 | 多言語・文化差でも意味重心が維持されるか | 限定的検証 |
| D. 文脈摂動耐性 | 周囲文脈を変えても意味位置が急変しないか | 部分検証（H-103・H-104） |

### Paper 2の正確な主張

```
「本研究では、semantic stabilityを4軸で整理する評価フレームワークを提案する。
 今回のPoCでは、その一部について初期検証を行った。」
```

**やらないこと（Paper 2のスコープ外）：**
- large-scale temporal evolution
- true multilingual robustness
- long-term adaptive anchor dynamics

→ これらはPaper 3以降で本格検証

## 4. 現在の位置づけ（研究プログラムとして）

意味束AIは現時点では「完成理論」ではなく「意味安定化に関する研究プログラム」として位置づけるのが最も正確である。

**確認済み（PoC①〜④）：**
- アンカー座標化によるクラスタ安定化（H-101：分散比0.052）
- 長期更新時のdrift低減（H-201：38.6%削減）
- 編集局所化（H-301/302：ρ<0.15で汚染32.6%）
- 圧縮後の意味保持（H-401/402：91.7%削減・0.963）

**Paper 2で検証予定：**
- 4軸stability frameworkの初期検証
- 身体性ベースアンカーの安定性比較
- ドメイン適応アンカー選定プロトコル

**Paper 3以降：**
- どのアンカーが最適か（大規模検証）
- 多言語・文化横断の本格検証
- Adaptive Anchor System

## 5. 問題設定

### 5.1 意味ドリフト問題

同一概念のembeddingは、以下の要因によって変動する：

- モデルの再学習・ファインチューニング
- コンテキスト変化
- 文化・時間的変化
- プロンプトの微妙な差異

この変動は「相対空間の構造的問題」であり、単なる誤差ではない。

### 5.2 長期整合性の欠如

LLMには、時間を超えて同一概念を同一構造で参照する仕組みが存在しない。
これは長期対話・Agent・企業知識管理での深刻な問題となる。

### 5.3 意味圧縮の欠如

RAGは情報を全文チャンクとして保持する。
これは長期化すると情報の肥大化・意味重心の不安定化を引き起こす。

## 6. 提案アプローチ

### 6.1 安定意味領域によるアンカー構築

LLM空間の内部から、モデル差・時間変化・文化変化・文脈摂動に対して比較的高い安定性を示す意味領域を探索する。この安定意味領域をアンカーとして採用し、全ての意味表現をアンカーとの類似度ベクトルとして再表現する。

### 6.2 Bundle構造による意味の構造化

意味を単一点ではなく、コア + 属性ベクトル群 + アンカー座標 + 更新履歴 として保持する。

### 6.3 参照再構成による意味圧縮

全文を保存するのではなく、bundle構造から必要時に再構成する。

## 7. 既存研究との差分

| アプローチ | できること | できないこと |
|-----------|-----------|-------------|
| 従来Embedding | 意味の類似度計算 | 長期的意味管理・安定座標 |
| RAG | 外部知識検索 | 意味構造管理・ドリフト検知 |
| Fine-tuning | タスク特化 | 外部からの意味管理 |
| Long context | 多情報の一括処理 | 意味構造の安定化・圧縮 |
| Anchored Embedding | モデル間整列 | 長期意味管理OS（目的が異なる） |
| Semantic Drift研究 | ドリフトの測定 | ドリフトの管理・修復 |
| keyword/ontology研究 | 単語・概念の定義 | 安定意味領域の探索・評価 |
| **意味束AI** | 安定意味領域の探索・4軸評価・長期管理 | LLMの言語生成（そこには関与しない） |

**最重要差分：**
- 「測定」から「管理」へ（既存Drift研究との差）
- 「単語」から「意味領域」へ（既存keyword研究との差）
- 「哲学的固定」から「統計的探索」へ（既存座標系研究との差）

## 8. 新規性の主張

1. **安定意味領域に基づくアンカー概念**：単語ではなく意味場として定義
2. **Semantic Stability 4軸評価フレームワーク**：安定性を評価可能な問題へ変換
3. **Bundle構造による意味の多次元保持**：単一点ではなく構造体として意味を管理
4. **参照再構成による意味圧縮**：全文保存なしに意味を再構成可能
5. **LLMに非侵襲的な外部意味管理層**：モデル内部を変更せずに意味を安定化

## 10. 限界と誠実な記述

- 4軸stability frameworkは提案段階（完全検証はPaper 3以降）
- 現時点のPoCは小規模（15〜110文）・単一ドメイン中心
- 文化横断性の定量的保証は未確定
- 時間ダイナミクスの詳細は非公開仕様
- 「幻覚を直接ゼロにする」技術ではない（検知・抑制の補助として機能する）
